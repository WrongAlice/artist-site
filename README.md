# Artist site template

A simple one-page portfolio that runs directly in a browser. There is no build step or account required.

## Open it in VS Code

1. Unzip this folder and open `artist-site` in VS Code.
2. Open `index.html` in a browser. For automatic refresh while editing, the VS Code Live Server extension is optional.
3. Search `index.html` for `YOUR NAME`, `Your Name`, `hello@example.com`, and the sample text. Replace them with your own details.
4. Create an `images` folder. Add your photos as `work-01.jpg`, `work-02.jpg`, and `work-03.jpg`. The sample panels show until those images exist. You can also change the filenames in the three `<img>` tags.
5. Change the artwork titles and medium/year labels. Edit colors near the top of `styles.css` if you like.

## Put it on GitHub Pages

Create a public GitHub repository, then upload the **contents** of this folder (`index.html`, `styles.css`, and your `images` folder) to its root. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will show the site address on that page once published. Keep the repository free of private files or information you do not want public.

The email links use `mailto:` and open a visitor's email app. There is no checkout or contact form. You can add a shop link later when you choose where to sell.
